# Data provenance

`data/network.json` is generated by `python -m agla.network.build` from the files below. Nothing in it is invented: every value comes from an official source, OpenStreetMap, or a hand-made row in this folder that says where it came from.

## Official snapshots (`data/raw/`, fetched 2026-10-23)

| File | Source | What it gives |
| --- | --- | --- |
| `dmrc_api/snapshot.json` | DMRC journey-planner API `backend.delhimetrorail.com/api/v2/en/` (`line_list`, `stations`, `station_by_line`) | 254 DMRC + Rapid Metro stations, coordinates, line order |
| `dmrc_api/segments_*.json` | same API, `station_route/{a}/{b}/least-distance/{time}` for every adjacent pair | minutes between neighbouring stations, adjacent-pair fares |
| `dmrc_api/od_fares_airport_rapid.json` | same API, every station pair on Airport Express and Rapid Metro | official fare tables -> `data/fares/*.csv` |
| `dmrc_api/fare_samples.json`, `cross_operator_samples.json` | same API, sampled pairs, weekday + Sunday | fare verification (`scripts/verify_fares.py`) |
| `nmrc/journey_planner_from_sector51.csv` | NMRC journey planner (nmrcnoida.com) | Aqua Line order, cumulative minutes and km |
| `osm/*.json` | OpenStreetMap via overpass-api.de | Aqua Line coordinates, Krishna Park Extension fix |

The DMRC API is undocumented (it's what delhimetrorail.com calls) and rejects non-browser requests, so it was read once through a browser (Playwright) and snapshotted. The app never calls it at runtime.

**Why not GTFS?** plan.md named the DMRC GTFS feed on Delhi Open Transit Data. On 2026-10-23 its download form returned `DMRC_GTFS.zip` as a 404 for every file (the file is missing server-side), and the feed has no fare files anyway.

## Manual files (this folder)

| File | Why |
| --- | --- |
| `aqua_line.csv` | Aqua Line isn't in the DMRC API. Order, minutes and km from the NMRC planner; coordinates from OSM. |
| `links.csv` | Topology fixes: Green Line branch joins at Ashok Park Main; Rapid Metro loop is one-way; walking interchanges (Sector 52 <-> Sector 51, Dhaula Kuan footbridge). |
| `coords.csv` | Krishna Park Extension: the API repeats Janakpuri West's coordinates. |
| `states.csv` | Haryana / UP stations (everything else is Delhi). |
| `names.csv` | Display names where the API name is messy. |
| `aliases.csv` | Abbreviations, landmarks and old names people type ("RC", "HKV", "cyber hub"). |

## Known approximations

- **Distance** is the sum of straight-line distances between consecutive stations, not DMRC's track distance. Adjacent pairs that the official fare places across the 2 km slab boundary get a corrected `fare_km`. Trips within about 1.5 km of the 32 km boundary can still land in the neighbouring slab (2 such pairs in the samples).
- **Times** are the DMRC planner's adjacent-station times; two placeholder values (2 seconds) were replaced with a distance estimate and are listed in `network.json` -> `meta.flagged_edges`. Aqua Line times are NMRC's indicative 2 min per station.
- **Fare check** (`uv run python -m scripts.verify_fares`): 376/384 official fares match. The rest are the 32 km boundary above and two Airport Express trips where DMRC's least-distance route differs from our fastest route.
